# AutoClicker Pro

Chrome / Edge uzantısı. Sayaç bitince (veya buton aktif olunca) İleri / Devam / Next gibi düğmelere otomatik tıklar. Site bazlı profiller, sihirbaz, durum balonu ve acil durdur destekler.

## Kurulum

1. `chrome://extensions` (veya Edge’de `edge://extensions`) açın.
2. **Geliştirici modu**nu açın.
3. **Paketlenmemiş uzantı yükle** → bu klasörü seçin.
4. Popup’tan **Profil Ayarları** → **Sihirbaz** veya **Hazır Profilleri Ekle**.

ADBS (`adbs.uab.gov.tr`) için hazır profil vardır.

## Kullanım

- Durum balonu: eşleşen sitede sağ altta görünür.
- Acil durdur: balondaki **Durdur**, popup’taki kırmızı buton veya `Ctrl+Shift+X`.
- Tıklama limiti `0` ise sınırsızdır. Bekleme (cooldown) peş peşe basmayı keser.
